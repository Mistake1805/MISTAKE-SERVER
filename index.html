02 · Installation

SETUP GUIDE

A clean, six-step walkthrough. Follow in order — screenshots marked with placeholders can be replaced with real captures by dropping in an <img>.

00
Accounts

Create a TLauncher Account

Before we can build a custom version, we need a TLauncher account linked to the launcher. This is what the launcher uses to remember your settings and synced instances.

  1. 1 Open TLauncher.
  2. 2 Click Configure Accounts.
  3. 3 Click Add.
  4. 4 Create a TLauncher Account.
  5. 5 Save the account.
  6. 6 Return to the launcher main screen.
i
Tip: Use a strong password. TLauncher accounts are local to the launcher and free to create. Download TLauncher from the official site: tlauncher.org.
01
Version

Create the Server Version

We need a clean, dedicated version pinned to Fabric 1.21.11. Use the settings below exactly — do not install anything from the catalog.

NameServer
Minecraft VersionFabric 1.21.11
Loader TypeFabric (Default Forge)
Loader VersionLeave Default
MemoryDefault
Skin SystemUnselect TL SKINs AND CAPE (IF THERE IS ONE)
Optimization FPSDisable

  1. 1 Click Create Version.
  2. 2 Fill in the settings above.
  3. 3 Do NOT install from catalog.
  4. 4 Click Create.
!
Don't install from the catalog. The bundled modpack we provide is hand-curated and tested. Catalog mods may break server compatibility.
02
First Boot

Launch Minecraft Once

A clean first launch generates the version folder structure we need in the next step.

  1. 1 Launch Minecraft.
  2. 2 Wait until you reach the Main Menu.
  3. 3 Close the game.
03
Mods

Install Mods

Drop the curated modpack into the version directory created in step 1.

  1. 1 Download Mods.zip from the downloads section.
  2. 2 Extract it.
  3. 3 Open TLauncher.
  4. 4 Click the Game Directory icon.
  5. 5 Open versions → Server.
  6. 6 Paste the mods folder.
  7. 7 Verify all .jar files exist.
versions/
└── Server/
    └── mods/
        ├── sodium-fabric-mc1.21.11.jar
        ├── lithium-fabric-mc1.21.11.jar
        ├── fabric-api-0.116.0.jar
        ├── voicechat-fabric-1.21.11.jar
        ├── Backpack-fabric-1.21.11.jar
        └── …and 100+ more
i
Verify before joining. Missing mods will cause the server to kick you on connect. Confirm the count matches the downloads page.
04
Optional

Install Resource Pack

Online players receive the pack automatically. This step is only required for offline / LAN testing.

  1. 1 Download the Resource Pack.
  2. 2 Copy the .zip into resourcepacks.
  3. 3 Enable it in-game from Options → Resource Packs.
i
Heads up: This is only required for offline players. Online players receive it automatically when connecting.
05
Optional

Install Shader Packs

Shaders dramatically upgrade the look of the world — realistic water, soft shadows, volumetric light. Pick the one that matches your PC and you're set.

  1. 1 Download the Shader Pack ZIP provided by the server administrator.
  2. 2 Extract the ZIP file.
  3. 3 Open the Minecraft Game Directory.
  4. 4 Open the folder:
    shaderpacks

    If the folder does not exist, launch Minecraft once with Iris installed and it will be created automatically.

  5. 5 Copy all extracted shader files (.zip) into the shaderpacks folder.
  6. 6 Do NOT extract the individual shader ZIP files.

    Each shader should remain as its own ZIP file.

  7. 7 Launch Minecraft and go to:
    Options › Video Settings › Shader Packs
    Then choose your preferred shader.

03 · FAQ

QUESTIONS

Common issues and how to fix them in under a minute.

Why can't I connect to the server?

Most connection issues come from a wrong IP/port or an outdated modpack. Verify the server address with the admin, then double-check you have all 42 mods installed in versions/Server/mods. Also confirm your client is on Fabric 1.21.11 — not vanilla or Forge.

Mods are missing in-game — what do I do?

Open the game directory, navigate to versions/Server/mods, and verify every .jar from the modpack is present. If a mod failed to download, re-extract the zip and replace the missing file. Re-launch the version after.

The resource pack isn't showing — fix?

Online players get the pack automatically. If you're offline, drop the .zip into resourcepacks, enable it in Options → Resource Packs, then rejoin the world.

Server offline / can't be reached?

The server may be restarting or the dynamic WAN IP may have changed. Wait 2–3 minutes and try again. If it persists, contact the admin in the Support section for the current IP and port.

"Outdated mods" warning appears on join?

This means the server was updated. Re-download the latest Mods.zip and replace the contents of versions/Server/mods. Restart the client and reconnect.
